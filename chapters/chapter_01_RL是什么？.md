### 核心循环

```
┌─────────────────────────────────────────────────┐
│                                                 │
│   AGENT  ──── action ────▶  ENVIRONMENT         │
│     ▲                           │               │
│     │                           │               │
│     └────── reward + state ─────┘               │
│                                                 │
└─────────────────────────────────────────────────┘
```

Agent 活在一个循环里：
1. **See** - 观察当前状态 (state)
2. **Do** - 执行动作 (action)
3. **Get** - 收到奖励 + 新状态 (reward + new state)
4. **Repeat** - 不断循环，慢慢变聪明

### 具体例子：格子迷宫 🐭

```
┌───┬───┬───┬───┐
│ 🐭 │   │   │   │
├───┼───┼───┼───┤
│   │ ■ │   │   │   ■ = 墙（不能走）
├───┼───┼───┼───┤
│   │   │   │ 🧀 │   🧀 = 奖励 (+1)
└───┴───┴───┴───┘
```

| 概念 | 定义 | 迷宫例子 |
|---|---|---|
| **State (s)** | Agent 当前观察到的情况 | 鼠标所在格子 (row, col) |
| **Action (a)** | Agent 可以执行的操作 | ↑ ↓ ← → |
| **Reward (r)** | 环境给的反馈信号 | 到达🧀得 +1，其他为 0 |

### 为什么用 RL 而不是写规则？

```
传统编程：                    强化学习：

规则 ──▶ 电脑 ──▶ 输出        经验 ──▶ Agent ──▶ 规则
```

RL 适合**规则难以手写**的场景 - 机器人走路、下棋、打游戏。
